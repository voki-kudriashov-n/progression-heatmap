# Как пользоваться Progression Heatmap

Этот дашборд помогает смотреть, как игровые метрики меняются по датам и группам уровней. Основной экран - тепловая карта: по горизонтали идут даты, по вертикали группы уровней, а цвет ячейки показывает значение выбранной метрики.

## 1. Выберите игру

В верхней части панели фильтров нажмите на иконку нужной игры:

- `MM` - Manor Matters
- `MyM` - Mystery Matters

При переключении игры меняется цвет панели фильтров и источник данных для графика. В локальном тестовом режиме обе игры могут использовать один CSV-образец. В Databricks каждая игра читает настроенную для нее таблицу.

## 2. Настройте фильтры

Фильтры находятся слева. Изменения в фильтрах не перестраивают текущий график сразу: можно спокойно выбрать все нужные параметры, а затем нажать `Применить`.

### Вид

- `Когорта уровней` - минимальная и максимальная группа уровней, которые нужно показать на графике.
- `Даты` - период дат для отображения.

Эти фильтры применяются к уже собранной таблице. Обычно они обновляются быстрее, чем сегменты.

### Сегменты

Эти фильтры ограничивают исходные данные до расчета heatmap:

- `Попытки` - только первая попытка или попытки 2+.
- `Платформа` - платформа игрока.
- `Тип трафика` - тип трафика.
- `Тип игрока` - плательщики или неплательщики.
- `ДРШ активирован` - наличие большого радужного шара: `Да` или `Нет`.

Если внутри фильтра выбраны все варианты, дашборд считает, что ограничения по этому фильтру нет.

### Величина

- `Величина` - показатель, который нужно показать на heatmap.
- `Расчет` - способ расчета величины.
- `Минимум наблюдений` - минимальное количество наблюдений для отображения процентной ячейки. Поле появляется только для процентных расчетов. Значение по умолчанию - `0`, поэтому по умолчанию ячейки не скрываются.

Доступные величины:

- `CF`, `CW`, `FF`, `FW`;
- `Попытки`;
- `Средняя попытка`;
- `Проигрыши`;
- `Победы`;
- `% проигрышей`;
- `% побед`;
- `Первые попытки`.

Доступные способы расчета зависят от выбранной величины:

- `Абсолютное` - количество событий.
- `Процент` - доля от всех наблюдений в ячейке.
- `Процент внутри исхода` - доля внутри побед или поражений. Используется для `FW`, `CW`, `FF` и `CF`.
- `Среднее` - среднее значение. Используется для `Средняя попытка`.

## 3. Нажмите Применить

После изменения фильтров нажмите `Применить`. До нажатия кнопки график не перестраивается, и на экране остается предыдущая версия heatmap.

Если меняете только даты или диапазон уровней, обновление обычно проходит быстрее, потому что дашборду не нужно заново собирать все данные.

## 4. Читайте heatmap

- Ось X - дата.
- Ось Y - группа уровней.
- Цвет ячейки - значение выбранной метрики.
- Пустые ячейки - данных нет или данных меньше, чем указано в `Минимум наблюдений`.

Справа от графика есть вертикальная цветовая шкала. Перетаскивайте красные верхнюю и нижнюю границы, чтобы вручную задать минимум и максимум цветового диапазона. Так можно приглушить сильные всплески и лучше рассмотреть остальные участки heatmap без нового сбора данных.

Наведите курсор на ячейку, чтобы увидеть детали:

- значение метрики;
- количество событий для выбранной величины;
- общее количество наблюдений;
- статус надежности выборки.

## 5. Навигация по графику

- Выделите область мышкой, чтобы приблизить участок графика.
- Двойной клик по графику сбрасывает приближение.
- Колесико мыши можно использовать для zoom.

## 6. Если график пустой

Проверьте, не слишком ли узко выбраны фильтры. Чаще всего помогает расширить даты, диапазон уровней или выбрать больше сегментов.
