# Как пользоваться Progression Heatmap

Этот дашборд помогает смотреть, как игровые метрики меняются по датам и группам уровней. Основной экран - тепловая карта: по горизонтали идут даты, по вертикали группы уровней, а цвет ячейки показывает значение выбранной метрики.

## 1. Выберите игру

В верхней части панели фильтров нажмите на иконку нужной игры:

- `MM` - Manor Matters
- `MyM` - Mystery Matters

При переключении игры меняется цвет интерфейса и источник данных для графика.

## 2. Настройте фильтры

Фильтры находятся слева.

### Вид

- `Когорта уровней` - минимальная и максимальная группа уровней, которые нужно показать на графике.
- `Даты` - период дат для отображения.

### Сегменты

Эти фильтры ограничивают данные, из которых строится график:

- `Попытки` - только первая попытка или попытки 2+.
- `Платформа` - платформа игрока.
- `Тип трафика` - тип трафика.
- `Тип игрока` - плательщики или неплательщики.
- `ДРШ активирован` - наличие большого радужного шара.

### Величина

- `Величина` - показатель, который нужно показать на heatmap.
- `Расчет` - способ расчета величины.
- `Минимум наблюдений` - минимальное количество наблюдений для отображения процентной ячейки. Значение по умолчанию - `0`, поэтому по умолчанию ячейки не скрываются.

## 3. Нажмите Применить

После изменения фильтров нажмите `Применить`. До нажатия кнопки график не перестраивается.

Если меняете только даты или диапазон уровней, обновление обычно проходит быстрее, потому что дашборду не нужно заново собирать все данные.

## 4. Читайте heatmap

- Ось X - дата.
- Ось Y - группа уровней.
- Цвет ячейки - значение выбранной метрики.
- Пустые ячейки - данных меньше, чем указано в `Минимум наблюдений`.

Справа от графика есть вертикальная шкала `Диапазон градиента`. Красные верхняя и нижняя границы задают минимум и максимум цветовой шкалы, поэтому можно приглушить сильные всплески и лучше рассмотреть остальные участки heatmap без нового сбора данных.

Наведите курсор на ячейку, чтобы увидеть детали:

- значение метрики;
- количество событий для выбранной величины;
- общее количество наблюдений;
- статус надежности выборки.

## 5. Навигация по графику

- Выделите область мышкой, чтобы приблизить участок графика.
- Двойной клик по графику сбрасывает приближение.
- Колесико мыши можно использовать для zoom.

## 6. Если график пустой

Проверьте, не слишком ли узко выбраны фильтры. Чаще всего помогает расширить даты, диапазон уровней или выбрать больше сегментов.
